CADENCE ARCADE

two Cadence 0.95.2 System 1 brains born in your browser, learning live · an Atari 2600 core and the released library run in web workers · every fiber and number is measured, nothing is staged speed full · 4× real time

What runs here. Each game is an Atari 2600 emulated in a worker. Its brain is born in a second worker with a fixed seed: a Cadence 0.95.2 System 1 brain, 7,056 sensory neurons for the 84 × 84 screen, an association cortex with a working trace, a motor cortex with one neuron per action, a critic and an associative memory, 456,000 synapses that settle together for every answer. It watches a scripted teacher play (Freeway: always up; Atlantis: always fire) and takes each watched screen as a lesson. Once its own answers agree with the teacher's often enough and it has watched one whole game, it takes the controls, and from then on it learns from the reward of its own actions. The brain is the released cadence-net wheel running in Python in your browser (Pyodide), the same Brain.compose call as the Python edition; the emulator is the 6502.ts core. Source and receipts.
