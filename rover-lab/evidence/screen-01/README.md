720-step protocol. The shared controller can stop outside the success radius.
Its behavior and latency gates fail. The numerical run is retained as a
development diagnostic and is excluded from the demo's measured claims.

The source inventory was expanded during implementation, so freeze and receipt
source lists differ. This directory is not a verified source-bound evidence
bundle. `screen-02` contains the declared nine-action development comparison,
an independent verification and a complete hash-matched source archive.
