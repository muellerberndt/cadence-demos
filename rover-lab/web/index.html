Experiment scope & measurement details +

This is a differential-drive simulation of a learned body model inside a supplied target controller. A single displayed run does not establish an advantage over adaptive or neural baselines, physical robot performance, or protected memory.

Targets reached count completed targets; attempts include target timeouts. Compute time includes model prediction, action selection and learning. The run record and receipt identify the protocol and phase measurements.

Every model and the rover body run in this page, in a worker beside the display. The Cadence brains use a JavaScript edition of the population solver of cadence-net 0.70.0, checked against the Python library. While the tab is hidden the life waits.
